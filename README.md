## Управление таблицами

В проекте реализована консольная база данных, которая поддерживает интерактивный режим управления таблицами. 

### Доступные команды:

* `create_table <имя_таблицы> <столбец1:тип> <столбец2:тип> ...` — создание новой таблицы. 
  *Поддерживаемые типы данных: `int`, `str`, `bool`.*
  *Столбец `ID:int` добавляется автоматически в качестве уникального ключа.*
* `list_tables` — вывод списка всех существующих таблиц.
* `drop_table <имя_таблицы>` — удаление таблицы.
* `help` — вывод справочной информации.
* `exit` — завершение работы программы.

## CRUD-операции

База данных поддерживает основные операции для работы с записями (CRUD). При создании новой записи поле `ID` генерируется автоматически.

**Доступные команды:**
* `insert into <имя_таблицы> values (<значение1>, <значение2>, ...)` — добавление новой записи. Все поля, кроме ID, обязательны для заполнения. Строковые значения указываются в кавычках.
* `select from <имя_таблицы> [where <столбец> = <значение>]` — вывод записей в виде отформатированной таблицы с возможностью фильтрации.
* `update <имя_таблицы> set <столбец> = <значение> where <столбец> = <значение>` — обновление данных по условию.
* `delete from <имя_таблицы> where <столбец> = <значение>` — удаление записей по условию.
* `info <имя_таблицы>` — вывод информации о структуре таблицы и количестве записей.
