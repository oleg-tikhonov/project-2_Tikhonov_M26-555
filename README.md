# Primitive DB

Локальная система управления базами данных с интерактивным интерфейсом командной строки. Проект позволяет создавать таблицы, управлять данными (CRUD-операции) и сохраняет всю информацию локально в формате JSON.

## Управление таблицами

В проекте реализована консольная база данных, которая поддерживает интерактивный режим управления таблицами. 

### Доступные команды:

* `create_table <имя_таблицы> <столбец1:тип> <столбец2:тип> ...` — создание новой таблицы. 
  *Поддерживаемые типы данных: `int`, `str`, `bool`.*
  *Столбец `ID:int` добавляется автоматически в качестве уникального ключа.*
* `list_tables` — вывод списка всех существующих таблиц.
* `drop_table <имя_таблицы>` — удаление таблицы.
* `help` — вывод справочной информации.
* `exit` — завершение работы программы.

## CRUD-операции

База данных также поддерживает основные операции для работы с записями (CRUD). При создании новой записи поле `ID` генерируется автоматически.

**Доступные команды:**

* `insert into <имя_таблицы> values (<значение1>, <значение2>, ...)` — добавление новой записи. Все поля, кроме ID, обязательны для заполнения. Строковые значения указываются в кавычках.
* `select from <имя_таблицы> [where <столбец> = <значение>]` — вывод записей в виде отформатированной таблицы с возможностью фильтрации.
* `update <имя_таблицы> set <столбец> = <значение> where <столбец> = <значение>` — обновление данных по условию.
* `delete from <имя_таблицы> where <столбец> = <значение>` — удаление записей по условию.
* `info <имя_таблицы>` — вывод информации о структуре таблицы и количестве записей.

## Продвинутые возможности (Декораторы и замыкания)

В проекте реализованы механизмы для повышения надежности и удобства использования на базе декораторов и замыканий:

* **Автоматическая обработка ошибок (`@handle_db_errors`):** Перехватывает частые исключения (неверный ввод, отсутствие таблиц, ошибки типов) и выводит понятные сообщения вместо аварийного завершения программы.
* **Защита от случайных удалений (`@confirm_action`):** Перед выполнением опасных операций (удаление таблицы или записей) система запрашивает подтверждение пользователя `[y/n]`.
* **Логирование времени выполнения (`@log_time`):** Выводит в консоль время, затраченное на выполнение ресурсоемких операций (добавление и поиск записей).
* **Кэширование запросов (`create_cacher`):** Повторные запросы `select` с идентичными условиями поиска обрабатываются мгновенно, возвращая результат из кэша (замыкания), без повторного сканирования базы данных.
